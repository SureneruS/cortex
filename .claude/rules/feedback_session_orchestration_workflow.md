Track all Cortex/session orchestration work in the personal Linear workspace (via `linear-personal` MCP, scoped to cortex project).

**Why:** Consistent tracking, no work lost between sessions, clear progress visibility. Migrated from GitHub Projects board to Linear for richer project management (milestones, priorities, triage).

**How to apply:**
- Log all features, bugs, and backlog items as Linear issues
- One issue per merge/commit to main — don't bundle multiple issues in one commit
- After each iteration: Suren verifies → adds feedback as new backlog items → we pick the next item
- Iterate continuously: pick → implement → verify → feedback → pick next
- Use `linear-personal` MCP tools to manage issues (only available from cortex project sessions)
