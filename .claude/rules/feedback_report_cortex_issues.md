Proactively report Cortex tooling issues and feature ideas via `/report-issue` — even minor ones.

**Why:** Small issues accumulate silently and never get fixed. Capturing them in the moment (when context is fresh) is far more valuable than trying to recall them later.

**How to apply:** Whenever you encounter unexpected behavior, need a workaround, or think "this should be better" while using Cortex tools — trigger `/report-issue` immediately. Use `mcp__linear-personal__save_issue` (Cortex team, Triage). If Linear MCP fails, fall back to `~/cortex/issues/` file. Never use other Linear MCPs.
